
# Custom OMA-URI Profiles

Custom OMA-URI profiles in Microsoft Intune provide a way to configure settings that are not available through the Settings Catalog or built-in templates.

By using OMA-URI settings, administrators can interact directly with Windows Configuration Service Providers (CSPs) and configure advanced device settings.

## What is an OMA-URI?

An OMA-URI (Open Mobile Alliance Uniform Resource Identifier) is a path used by Microsoft Intune to communicate with a specific Configuration Service Provider (CSP) on a Windows device.

Example:

./Device/Vendor/MSFT/RemoteDeviceLock/LockState
