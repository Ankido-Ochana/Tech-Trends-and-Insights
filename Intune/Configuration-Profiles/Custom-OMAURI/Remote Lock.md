
# Remote Lock (Preview)

Remote Lock is a new Microsoft Intune capability that allows administrators to remotely lock Windows devices without wiping user data.

This guide covers:

- What Remote Lock is
- How to configure Remote Lock using Custom OMA-URI profiles
- Locking and unlocking devices
- Optional lock screen messages
- Prerequisites and limitations
- Deployment recommendations

Remote Lock can be useful when a device is lost, stolen, or temporarily unavailable, while preserving enrollment, management, and user data.

## Related Technology

- Microsoft Intune
- Windows CSP
- RemoteDeviceLock CSP
- Microsoft Entra ID
- Custom OMA-URI Profiles
