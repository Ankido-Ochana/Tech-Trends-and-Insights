# Remote Lock (Preview)

Remote Lock is a Microsoft Intune capability that allows administrators to remotely lock Windows devices without wiping user data.

## What You'll Learn

This guide covers:

- What Remote Lock is
- How to configure Remote Lock using Custom OMA-URI profiles
- How to lock and unlock devices remotely
- Optional lock screen messages
- Requirements and limitations
- Deployment recommendations and best practices

Remote Lock can be useful when a device is lost, stolen, or temporarily unavailable, while preserving device enrollment, management, and user data.

## Related Technologies

- Microsoft Intune
- Microsoft Entra ID
- Windows Configuration Service Providers (CSPs)
- RemoteDeviceLock CSP
- Custom OMA-URI Profiles
