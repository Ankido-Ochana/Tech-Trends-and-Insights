# Windows 11 Compliance - MAA Connectivity Validation

## Overview

This repository contains resources related to Microsoft Intune compliance validation and the migration from Device Health Attestation (DHA) to Microsoft Azure Attestation (MAA).

https://techtrendsandinsights.blogspot.com/2026/09/windows-11-compliance-in-intune.html

## Contents

- MAA Connectivity Test Script
- Validation Guidance
- Network Troubleshooting
- Compliance Considerations

## Purpose

The purpose of this guide is to validate:

- DNS resolution
- TCP 443 connectivity
- HTTPS communication
- Proxy configuration
- SSL/TLS inspection
- Microsoft Azure Attestation endpoint reachability

This helps identify connectivity issues before investigating Intune compliance or Windows Health Attestation problems.
