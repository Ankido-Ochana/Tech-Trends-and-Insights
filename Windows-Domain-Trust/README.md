# Windows Domain Trust Toolkit

PowerShell tools and documentation for investigating and troubleshooting Windows domain trust and Machine Identity Isolation related issues.

## Overview

This project provides practical PowerShell tools for IT administrators troubleshooting Windows domain trust and secure channel issues.

The project is supported by technical guides published on Tech Trends and Insights.
