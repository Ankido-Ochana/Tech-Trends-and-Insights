# Microsoft OneDrive Pay-As-You-Go Storage

Published: September 2026

## Summary

OneDrive Pay-As-You-Go allows organizations to extend OneDrive storage beyond the included license quota and only pay for the additional storage consumed.

## Prerequisites

- Microsoft 365
- Azure Subscription
- Resource Group
- SharePoint or Global Administrator permissions

## Configuration Steps

1. Review OneDrive consumption
2. Enable Pay-As-You-Go
3. Connect Azure Subscription
4. Enable Microsoft 365 OneDrive Storage
5. Configure users
6. Configure budget alerts

## Recommendation

Enable the feature only for users with a business requirement and monitor costs regularly.
